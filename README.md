Catálogo de Filmes

Aplicação web para gerenciar um catálogo de filmes, com operações de CRUD: criar, ler, alterar e apagar.

Funcionalidades

O usuário pode cadastrar filmes e consultar, editar e remover os registros existentes. Os dados ficam em uma API simulada e são acessados pelo front-end
Cada filme possui: id, nome, genero e ano.
